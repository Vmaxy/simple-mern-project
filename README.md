MERN Image Posting Application

A full-stack web application built using the MERN stack that allows users to create image posts with captions and view them in a feed.

The project demonstrates how a React frontend communicates with a Node.js and Express backend, stores post information in MongoDB, and handles image uploads using ImageKit.

🚀 Features

Create Posts: Upload images with captions.

Image Upload: Store uploaded images using ImageKit.

Post Feed: Retrieve and display posts dynamically.

Database Integration: Store image URLs and captions in MongoDB.

REST API: Communicate between frontend and backend using HTTP requests.

React Routing: Navigate between the post creation and feed pages.
